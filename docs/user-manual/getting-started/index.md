# Getting Started

This section explains the concepts you need before you use any DeFi feature:
how the chain is structured, where your balances live, which address formats
exist and what the DFI token is used for.

Part of the [User & Protocol Manual](../index.md).

## Contents

| Document | What you learn |
| --- | --- |
| [Core concepts](core-concepts.md) | The DVM and the EVM layer, blocks and masternodes, fees, and the transaction lifecycle. |
| [UTXO and accounts](utxo-and-accounts.md) | The two balance models of DeFiChain and how value moves between them. |
| [Wallets and addresses](wallets-and-addresses.md) | Address formats, key types, authorisation and the account history of an address. |
| [DFI tokenomics](dfi-tokenomics.md) | The DFI token, its issuance, its roles in the protocol and how to read on-chain supply figures. |

## Suggested order

Read [Core concepts](core-concepts.md) first. It introduces the vocabulary used
by every other page of this manual — DVM, EVM, DfTx, UTXO, account, DAT,
masternode — and it is the shortest path to understanding the rest of the
protocol.

If your goal is to receive and send funds, continue with
[Wallets and addresses](wallets-and-addresses.md) and
[UTXO and accounts](utxo-and-accounts.md).
