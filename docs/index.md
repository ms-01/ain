# DeFiChain Documentation

The canonical documentation suite of this repository. It is organised into three manuals, each written for a different audience, as defined by [ADR-0002](developer-manual/adr/ADR-0002-documentation-structure.md).

## Manuals

- [User & Protocol Manual](user-manual/index.md) — using the protocol: wallets, DeFi actions, staking, governance.
- [Node Software Manual](node-manual/index.md) — running the software: installation, configuration, operations, RPC/CLI reference, troubleshooting.
- [Developer & Architecture Manual](developer-manual/index.md) — changing the software: architecture, codebase map, consensus rules, subsystems, build and test workflow, ADRs.

## Contributing

Contributors start with the authoring guide in `docs/README.md`: it explains the layout, the document types, the Markdown conventions and the local preview commands.
